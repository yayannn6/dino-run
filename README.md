# Dino Run — Privacy Policy

Halaman kebijakan privasi untuk aplikasi Android **Dino Run — Neon Meteor Dash**
(`com.boyannnz.dinorun`).

Halaman ini dwibahasa (Indonesia / English) dan tidak memakai dependensi apa pun —
satu file `index.html` saja.

## Cara publish di GitHub Pages

1. Buat repository **publik** baru bernama `dino-run-privacy`.
2. Upload `index.html` dan `README.md` ke branch `main`.
3. Buka **Settings → Pages**.
4. Bagian **Source**, pilih **Deploy from a branch**, lalu `main` / `(root)`, klik **Save**.
5. Tunggu 1–2 menit. URL-nya akan menjadi:

   ```
   https://<username-github-anda>.github.io/dino-run-privacy/
   ```

6. Tempel URL itu ke Google Play Console:
   - **Kebijakan Aplikasi → Konten aplikasi → Kebijakan Privasi**
   - **Store listing → Privacy Policy**

Deep link bahasa juga tersedia:
`…/dino-run-privacy/#id` dan `…/dino-run-privacy/#en`

## Kalau isinya perlu diubah

Edit `index.html`, commit, lalu GitHub Pages akan otomatis menerbitkan ulang.
Jangan lupa perbarui tanggal **"Berlaku sejak / Effective date"** di bagian atas
halaman setiap kali ada perubahan berarti.

## Kapan kebijakan ini WAJIB diperbarui

- Menambahkan pembelian dalam aplikasi (IAP) → tambahkan bagian tentang data transaksi
- Menambahkan papan skor daring / login → tambahkan bagian akun & data yang dikirim
- Menambahkan analitik atau pelaporan crash (Firebase, dsb.) → sebutkan SDK-nya
- Mengganti atau menambah jaringan iklan (mediasi) → sebutkan pihak ketiganya
